# Données personnelles — agemocratie.fr

Version du 22 novembre 2026.

## Responsable et contact

Le service est exploité par Achille Thibon-Soula.

Pour toute question ou demande concernant vos données personnelles : agemocratie@gmail.com.

## Objet du service

agemocratie.fr permet de consulter l’avis des étudiants de Jussieu pour les assemblées générales étudiantes. La participation en ligne est facultative. Refuser d’utiliser le site n’empêche pas de participer à l’AG et n’entraîne aucune pénalité.

Le site vérifie l’accès à une adresse @etu.sorbonne-universite.fr ou @sorbonne-universite.fr, délivre un code par adresse et par AG, limite les participations avec le même code et présente les résultats des consultations. Un vote enregistré est définitif dans le fonctionnement du site.

## Données utilisées

L’adresse universitaire est utilisée pour transmettre un code temporaire de vérification. Le code personnel d’AG est ensuite affiché sur le site, sans être envoyé par mail.

Les données applicatives comprennent les empreintes de vérification, une empreinte de l’adresse propre à chaque AG, les codes sous empreinte, les jetons d’accès, les participations, les choix exprimés et les informations nécessaires à la sécurité. Selon le sujet de la consultation, les réponses peuvent exprimer des opinions politiques ou syndicales.

Les données sont pseudonymisées. Les informations de vérification, les codes et les bulletins sont conservés dans des tables séparées. Les prestataires techniques traitent également des informations de connexion nécessaires à leurs services, dont les adresses IP.

Cloudflare fournit l’hébergement du site et la base de données D1. Google fournit le service d’envoi des codes de vérification et la messagerie de contact. Ces prestataires peuvent traiter des données dans différents pays.

## Conservation

Le code de vérification expire après dix minutes. Les vérifications expirées sont supprimées lors des demandes et par la maintenance périodique. Les compteurs anti-abus utilisent une fenêtre de quinze minutes et leurs enregistrements périmés sont purgés périodiquement.

Les données actives d’une AG sont supprimées trente jours après la dernière fin programmée de ses sujets. Pour une AG sans sujet, ce délai court à partir de sa création. La suppression concerne l’AG, ses sujets, ses résultats, ses choix, ses codes, ses vérifications, ses empreintes de délivrance, ses émargements et ses bulletins.

La maintenance s’exécute toutes les cinq minutes, par lots de cinq AG. Le traitement par lots et les interruptions du service peuvent décaler l’exécution effective. Le journal des actions administrateur est conservé trente jours. Les comptes administrateur sont conservés pendant l’exploitation du service.

Les sauvegardes et copies techniques suivent les mécanismes des prestataires. D1 Time Travel conserve un historique de restauration de sept jours sur l’offre gratuite ou de trente jours sur l’offre payante. La suppression de la base active est distincte de l’expiration de cet historique. Les messages reçus dans la boîte universitaire restent sous le contrôle de leur destinataire.

Les copies des nouveaux mails de vérification dans le compte expéditeur font l’objet d’un nettoyage automatique après l’envoi, avec reprise en cas d’échec temporaire. Elles peuvent être visibles pendant ce délai. Les copies présentes avant l’activation de ce mécanisme sont conservées. La suppression d’une copie dans le compte expéditeur ne rappelle pas le message reçu par l’étudiant et ne supprime pas les métadonnées du service de messagerie.

## Cookies

Les cookies du site servent à la vérification de l’adresse, à l’accès à l’AG, à la session administrateur et à la protection des formulaires.

- Vérification temporaire de l’adresse : dix minutes.
- Accès à l’AG, session administrateur et protection CSRF : quatre heures.

Cette version n’ajoute aucun outil publicitaire ni de mesure d’audience.

## Demandes concernant vos données

Vous pouvez écrire à agemocratie@gmail.com pour exercer les droits applicables à vos données, notamment l’accès, la rectification, l’effacement ou la limitation. L’opposition et la portabilité s’exercent lorsque leurs conditions sont réunies.

Précisez votre demande et l’AG concernée. N’envoyez ni code de vote, ni mot de passe, ni pièce d’identité spontanément. Une vérification proportionnée de l’identité peut être demandée en cas de doute raisonnable.

Une réponse est apportée en principe dans un mois. Lorsqu’une prolongation est applicable, elle est expliquée dans le premier mois. Les demandes sont traitées à partir des données disponibles, sans créer de nouvelle correspondance entre une identité et un bulletin.

Vous pouvez adresser une réclamation à la CNIL : https://www.cnil.fr/fr/plaintes.


## Questions envoyées dans la FAQ

Le formulaire transmet uniquement le texte de votre question, sans demander de nom, de code de vote ou d’adresse mail. Les administrateurs peuvent consulter ce texte, le reformuler pour retirer des informations personnelles et publier une question avec sa réponse. Ne transmettez aucune information personnelle ou confidentielle. Les questions non publiées sont supprimées automatiquement après 30 jours ; les réponses publiées restent accessibles jusqu’à leur suppression par un administrateur. Les compteurs techniques de limitation des demandes sont temporaires, comme les autres protections du service. Pour demander la suppression d’un texte, utilisez le contact indiqué dans cette notice.
